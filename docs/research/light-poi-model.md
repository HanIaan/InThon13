# 빛 L1 — 상가·공장 분포를 이용한 NASA 야간광 200m 다시메트릭 다운스케일

작성: 2026-11-01 (Worker WL-light-poi). 대상: `feature/light-poi-lablup` (integration/trial `9ccbd91` 기준).

## 1. 요약

- 현행 L0은 NASA VNP46A3 463m 픽셀을 200m 격자에 면적 비율로 나누므로 한 픽셀 안의 격자 값이 거의 같습니다.
- L1은 상가 점포·야간 업종·공업용지·주요도로를 특성으로 한 **지수가중(exp) 공간 재분배**입니다. 각 픽셀 안에서 **면적가중 평균이 원 픽셀 값과 같도록** 정규화합니다.
- 3×3 픽셀(~1.4km) 집계 → 463m 재분배 스케일 이전 검증에서 **MAE 10.256 → 8.497 (-17.1%)**, 공간 5-fold **5/5 개선**, 픽셀 내 순위상관 0.506, 픽셀 내 분산 재현율 0.66.
- 보조 검증(S-DoT 야간 lux, 센서 709개) 순위상관 **0.0886(L0) → 0.0939(L1)**, 악화 없음.
- 채택 기준 충족 → **채택 권고(adopted=true)**. 서비스는 `LIGHT_MODEL=poi`(기본 off)로 켜며, 상태는 `estimated`, method는 `pixel_overlay_poi`입니다.
- 서울 15,685셀 결과: L0 대비 15,289셀 값이 바뀌고, L1/L0 비율 p5 0.788 / p50 1.000 / p95 1.171입니다. 픽셀 내 표준편차는 픽셀 값의 약 8.4%입니다.

## 3. 방법

### 3.1 특성 (7개)

모든 거리·면적·길이는 EPSG:5179(미터)에서 계산하고, 조회점(200m 셀 중심 또는 463m 픽셀 중심) 기준 반경으로 집계합니다.

| 특성 | 정의 | 변환 | 원천 |
| --- | --- | --- | --- |
| `stores_100` | 반경 100m 상가 점포 수 | log1p | 상가 |
| `stores_300` | 반경 300m 상가 점포 수 | log1p | 상가 |
| `nightlife_300` | 반경 300m 주점·노래방·숙박 점포 수 (중분류 주점/일반·기타 숙박, 소분류에 ‘노래’) | log1p | 상가 |
| `late_night_300` | 반경 300m 편의점 및 상호명 24시·24시간·24h 점포 수 | log1p | 상가 |
| `industrial_frac_300` | 반경 300m `landuse=industrial` 면적 / 원 면적 | identity | OSM |
| `industrial_site_300` | 반경 300m `man_made=works` + `building=industrial`·`warehouse` 중심점 수 | log1p | OSM |
| `major_road_m_300` | 반경 300m 주요도로(motorway·trunk·primary·secondary·tertiary + link) 길이 | log1p | OSM |

서울 15,685셀에서 특성 값이 0이 아닌 비율: `stores_300` 80.0%, `nightlife_300` 57.5%, `late_night_300` 65.1%, `major_road_m_300` 78.3%, `industrial_frac_300` 8.5%, `industrial_site_300` 5.9%.

### 3.2 모델

```
z_k     = (transform(feature_k) - mean_k) / std_k     # 픽셀 표본으로 표준화
w       = exp(Σ_k β_k z_k)
mean_w  = Σ_{c∈pixel} (area_c · w_c) / Σ area_c       # 배정된 셀들의 면적가중 평균
value_c = pixel_radiance × w_c / mean_w
```

- 셀은 **유효 NASA 픽셀 중 겹치는 면적이 가장 큰 픽셀**에 배정합니다(동률은 pixel_id 사전순). 유효 픽셀이 없는 셀은 `missing`입니다.
- 위 정규화로 각 픽셀에 배정된 셀들의 **면적가중 평균은 원 픽셀 값과 정확히 같습니다**(전 셀 검증 최대 상대오차 3.7e-16).
- 지수는 학습 후 [-3, 3]으로 자릅니다(서울 셀 실제 p5/p50/p95 = -0.480/0.375/0.700, 가중치 0.62/1.45/2.01).

### 3.3 β 학습과 스케일 이전 검증

관측 목표가 463m보다 성긴 구조만 있어, 다음 스케일 이전 검증을 사용했습니다.

1. 유효 픽셀을 3×3 완전 블록 849개(~1.4km)로 묶고 블록 평균 `B`를 만듭니다.
2. `B`를 같은 가중식으로 9개 463m 픽셀에 재분배합니다.
3. 실제 463m NASA 값과 비교합니다. 기준선 L0는 블록 안에서 균일한 `B`입니다.

β는 블록별로 중심화한 특성과 `log(radiance/B)`의 Ridge 회귀(절편 없음)로 적합했습니다. 블록 중심화로 인해 재분배 정규화 상수는 설계행렬과 직교하므로, 이 회귀는 근사가 아니라 로그선형 모델 계수를 그대로 복원합니다. 공간 fold는 15×15픽셀(~7km) 슈퍼블록 단위로 5개로 나눠 학습/검증이 1km 이웃을 공유하지 않게 했습니다. Ridge α는 0.03~10에서 평균 MAE가 8.497~8.504로 거의 같아 **α=10**을 선택했습니다.

## 4. 학습된 계수와 해석

표준화 특성 기준 β입니다(표준편차 1 증가 시 로그 밝기 변화).

| 특성 | β | 해석 |
| --- | ---: | --- |
| `stores_300` | **+0.252** | 반경 300m 점포 밀도가 가장 큰 양의 신호. 상업·유동인구 중심지가 더 밝음 |
| `major_road_m_300` | **+0.175** | 주요도로 길이(가로등·차량·간판)가 두 번째로 큼 |
| `nightlife_300` | +0.036 | 야간 영업 업종은 추가 양의 신호(점포 수와 상관이 있어 크기는 작음) |
| `industrial_frac_300` | +0.024 | 공업용지 면적 비율. 공장지대에서 국지적으로 밝기를 올림 |
| `industrial_site_300` | +0.024 | 공장·창고 개수 |
| `late_night_300` | +0.009 | 24시 업종. 편의점이 점포 밀도에 이미 반영되어 한계 기여가 작음 |
| `stores_100` | -0.020 | 300m 점포 수와 강하게 겹치는 근거리 변수 → 상쇄(음수). 해석은 “100m 근접 점포는 300m 밀도 대비 추가 밝기 없음” |

계수는 `backend/app/modeling/light/artifacts/light_poi_model_v1.json`의 `model.coefficients`에, 표준화 평균·표준편차는 `model.standardisation`에 있습니다. 요청 격자 15,685셀의 `w` 지수는 같은 JSON의 `cell_exponent`에 들어 있어, 추론은 이 파일만 읽습니다.

## 5. 검증

### 5.1 스케일 이전 (3×3 픽셀 → 463m, 공간 5-fold)

| fold | 검증 블록 | L0 MAE | L1 MAE | L0 RMSE | L1 RMSE | L1 픽셀내 Spearman | L1 분산 재현율 |
| ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 170 | 9.544 | **7.480** | 11.308 | **8.992** | 0.507 | 0.636 |
| 1 | 170 | 10.252 | **8.548** | 12.058 | **10.216** | 0.507 | 0.725 |
| 2 | 170 | 10.026 | **8.919** | 11.981 | **10.854** | 0.498 | 0.684 |
| 3 | 170 | 10.411 | **9.061** | 12.337 | **10.712** | 0.466 | 0.609 |
| 4 | 169 | 11.044 | **8.478** | 12.967 | **10.052** | 0.555 | 0.643 |
| 평균 | 849 | **10.256** | **8.497** | **12.130** | **10.165** | **0.506** | **0.659** |

- MAE -17.1%, RMSE -16.2%, **5/5 fold 개선**.
- L0는 블록 안에서 상수가 되어 픽셀 내 순위상관이 정의되지 않습니다(0). L1은 픽셀 내 변동의 약 66%를 재현합니다.
- 단위: nW/cm²/sr. 블록 평균 대비 오차이므로 절대값은 지역 밝기에 비례합니다.

### 5.2 보조 검증 (S-DoT 야간 lux와 순위상관만)

- 야간(22–01시) 유효 lux 표본 12개 이상 센서 709개. `light_*` 품질 플래그 행 제외, `dark_hours_zero` 0 lux는 정상값으로 유지.
- Spearman(센서 야간평균 lux, 셀 값): **L0 0.0886 → L1 0.0939**. 악화 없음(개선).
- 절대 단위가 달라 순위만 비교했고, lux는 점수에 사용하지 않습니다.

## 7. 서비스 도입

- `services/precompute.py`에서 환경변수 **`LIGHT_MODEL`**을 읽습니다. 기본값 `overlay`는 기존 L0와 완전히 동일합니다(운영자가 켜기 전까지 동작 불변).
- `LIGHT_MODEL=poi`이면:
  - `method="pixel_overlay_poi"`, `status="estimated"`, `source="nasa_black_marble"`, `raw_unit="nW/cm2/sr"`.
  - `note="월간 위성값을 상가·공장 분포로 200m에 재분배한 추정; 저녁·밤·새벽 동일 값이며 관측 시각은 미제공."`
  - 신뢰도는 기존 `0.55 × 피복률 × 품질(QF1 0.8)`에 모델 불확실성 계수 **0.9**를 곱합니다.
  - NASA 결측·QF2/255 픽셀만 있는 셀은 여전히 `missing`.
- 아티팩트 경로는 `LIGHT_POI_ARTIFACT`로 덮어쓸 수 있고, 기본은 `backend/app/modeling/light/artifacts/light_poi_model_v1.json`입니다.
- 오프라인 결과물: `data/processed/light_poi_cell_indicators.sqlite`(L1 사전계산 스냅샷, git 제외), `data/processed/light_poi_cell_comparison.csv`(15,685행 L0/L1 비교, git 제외).

## 8. 한계

1. **검증 해상도**: 실제 200m 관측이 없어 463m 스케일 이전으로만 평가했습니다. 200m 적용은 모델 가정의 외삽입니다.
2. **시간 해상도**: VNP46A3 월간 값이라 저녁·밤·새벽을 구분하지 않습니다. VIIRS 관측 시각(~01:30)과 상가 스냅샷(2026-09-30)의 시점 차이가 있습니다.
3. **특성 대리성**: 상가 밀도·도로 길이는 “빛을 내는 활동”의 대리변수입니다. 가로등만 밝고 상가가 적은 외곽 간선도로, 대형 조명시설(경기장·터널 입구)은 과소/과대 추정될 수 있습니다.
4. **공간 단위 불일치**: 학습은 463m 픽셀 중심 특성, 적용은 200m 셀 중심 특성입니다(점 지원 가정).
5. **공업 특성 희소성**: `industrial_*`는 각각 8.5%/5.9% 셀에서만 0이 아니어서, 공장지대 밖에서는 사실상 점포·도로 특성이 결정합니다.
6. **S-DoT 보조 검증 한계**: lux는 센서 주변의 국지 조도이고 0값이 많아 순위상관이 낮습니다(0.09). 절대 밝기 보정에는 쓰지 않았습니다.
7. **채택 후 재보정 필요**: L1은 원값 분포를 픽셀 안에서 바꾸므로 서울 백분위 보정(`calibration_seoul.json`)을 L1 스냅샷으로 다시 생성해야 합니다. 본 작업에서는 보정 파일을 수정하지 않았습니다.

## 9. 채택 권고

- 채택 기준(스케일 이전 fold 4/5 이상 개선 + 보조 검증 비악화)을 **충족**했습니다(5/5, 보조 개선).
- 권고: **`LIGHT_MODEL=poi`를 승인 후 켜고, `calibration_seoul.json`을 L1 스냅샷 기준으로 재생성**한 뒤 Supabase 재적재. 그 전까지 기본값 off를 유지합니다.
- 트레이드오프: L1은 픽셀 평균을 보존하므로 서울 전체 분포는 거의 그대로이고, **픽셀 내부의 상대 위치**만 바뀝니다. 검증된 개선은 “같은 463m 안에서 어느 200m가 더 밝은가”에 대한 것입니다.
