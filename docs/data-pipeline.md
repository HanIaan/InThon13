# 감각 데이터 파이프라인 (소음 · 빛공해 · 혼잡도)

`tools/build_sensory_data.py` 한 번 실행으로 서울 **100m 격자 60,606칸 × 시간대 4개** 점수를 만든다.
시간대와 필드는 [`frontend-integration.md`](frontend-integration.md)의 API 계약(`time_slot`, `*_score`, `confidence`)에 맞췄다.

```bash
pip install pandas geopandas scipy openpyxl
python3 tools/build_sensory_data.py   # 약 1분
python3 tools/validate_light.py       # 빛 검증 리포트
```

원본 파일은 용량이 커서 git에 없다. 받는 곳은 [`data/raw/README.md`](../data/raw/README.md).

### grid_100m.csv.gz 필드
| 필드 | 설명 |
|---|---|
| `cell_id`, `lng`, `lat` | 칸 ID, 칸 중심(WGS84). 폴리곤은 중심 ±50m (위도 ±0.00045°, 경도 ±0.000567°) |
| `dong`, `dong_name`, `gu` | 행정동 (8자리 문자열로 읽을 것) |
| `noise_db_{slot}` | 추정 소음 dB (slot = day/evening/night/dawn) |
| `noise_score_{slot}` | 0~100, `clip((dB−40)/30)×100` (기획서 실측 지수 공식) |
| `light_raw_{slot}` | 추정 야간 밝기 (nW/cm²/sr, 위성 단위) — evening/night/dawn만 |
| `light_score_{slot}` | 0~100 — evening/night/dawn만. **day는 없음 → API에서 `light_score: null`, `status: "not_applicable"`** |
| `crowd_score_{slot}` | 0~100, 동 단위 값 |
| `noise_sensor_dist_m`, `light_sensor_dist_m` | 가장 가까운 S-DoT까지 거리 (화면에 함께 표시 권장) |
| `noise_conf`, `light_conf`, `crowd_conf` | 0~1. 지도 투명도(`confidence`)에 사용 |

**모든 `*_score`는 높을수록 부담이 크다** (시끄러움 / 밝음 / 붐빔). 데이터 상태는 전부 추정이므로 API에서는 `data_status: "estimated"`.

### 시간대 (API 계약 기준)
| time_slot | 시간 | 빛 지표 |
|---|---|---|
| day | 07–18 | 미적용 |
| evening | 18–22 | 적용 |
| night | 22–02 | 적용 (위성 촬영 시각 약 01:30과 겹침) |
| dawn | 02–07 | 적용 |

## 2. 계산 방법

### 🔊 소음
1. S-DoT 2주(2026-10-05~10-18) 시간대별 중앙값 dB
2. 상가 소음원 밀도: 업종별 가중치 × 시간대 영업 활동도 × 층 보정(1층·지하 1.0 / 2~3층 0.6 / 4층+ 0.3), 반경 약 150m 가우시안
3. 환경 모델 `dB = a + b·log(1+소음원 밀도)` (센서 위치에서 최소제곱)
4. 격자 dB = `w × 600m 안 센서 IDW + (1−w) × 환경 모델`, `w = exp(−가장 가까운 센서 거리/300m)`

### 💡 빛공해 (2단계)
1. **1차 — NASA Black Marble** (VNP46A3 월간, 약 460m, 12개월 평균): 동네 전체의 실제 위성 밝기
2. **2차 — 상가정보로 100m 분해**: 500m 칸 안의 100m 칸들에 `상가 빛 밀도 + α × 평균` 비율대로 NASA 값을 나눠 담음. **500m 평균은 NASA 실측 그대로 유지.** α는 S-DoT로 5겹 교차검증해 선택(0.5)
3. 저녁·새벽은 업종별 영업 활동도 비율로 조정
4. 점수: 로그 밝기를 서울 5~95% 구간으로 0~1 → ×100. 100m 안 S-DoT가 **0보다 큰 값**을 재면 기획서 공식 `0.4×실측(1→30 lux 로그) + 0.6×추정`

### 👥 혼잡도
1. 생활인구 2026년 9월, 내국인+장기외국인+단기외국인 합산, 추석 연휴(9/24~27) 제외
2. **활동 인구 = 시간대 평균 − 새벽 3~5시 평균**(자고 있는 주민 제외) → 면적으로 나눠 밀도
3. 점수: `log(1+밀도/1000) / log(1+서울 상위 5% 밀도/1000)` × 100 (0명=0점)

### 업종 가중치
| 그룹 | 예 | 소음 | 빛 | 활동도 day/eve/night/dawn |
|---|---|---|---|---|
| club | 무도 유흥 주점 | 3.0 | 3.0 | 0.1/0.8/1.0/0.6 |
| bar | 요리주점·생맥주·일반유흥 | 2.0 | 2.0 | 0.2/1.0/1.0/0.3 |
| karaoke | 노래방 | 2.0 | 2.5 | 0.3/1.0/1.0/0.4 |
| latenight | 편의점·PC방·모텔·게임장 | 0.6 | 2.0 | 1.0/1.0/1.0/0.9 |
| delivery | 치킨·피자·버거 | 0.8 | 1.0 | 0.6/1.0/0.6/0.1 |
| leisure | 당구·볼링·골프연습·헬스 | 0.6 | 1.0 | 0.6/1.0/0.5/0.1 |
| food / retail | 그 외 음식 / 소매 | 0.6 / 0.2 | 1.0 / 0.7 | 낮 위주 |
| other | 사무실·학원·병원 등 | 0.05 | 0.15 | 낮 위주 |
| excluded | 펜션(서울 8,117곳, 공유주택 추정)·고시원 | 0 | 0 | |

모든 가중치는 **초기 추정치**다 (기획서 12장 한계와 동일).

## 3. 검증 결과 (정직하게)

### 빛: NASA 1차 → 상가 2차
| 검증 | 1차 NASA | 2차 NASA+상가 |
|---|---|---|
| S-DoT 심야 조도와 순위 상관 (센서 지점, 5겹 교차검증) | 0.05 | **0.12** |
| S-DoT와 순위 상관 (동 단위 평균) | 0.07 | 0.10 |
| 대로변 센서가 주택가보다 밝게 나올 확률 | 0.72 | 0.72 |
| 공원이 상업지역보다 어둡게 나올 확률 | 0.49 (구분 못 함) | **0.74** |
| 상가 빛 밀도 ↔ NASA 일치도 (500m 칸) | | **0.85** |

- **상가 밀도가 위성 밝기를 잘 설명한다(0.85)** → 상가를 100m 분해 근거로 쓰는 것이 타당하다.
- 2차에서 **공원은 어둡게, 대로변·시장·상업지는 밝게** 바뀌어 지점 일치도가 2배 이상 올랐다.
- 다만 S-DoT와의 상관이 낮은 가장 큰 이유는 **S-DoT 조도 자체**다: 심야 45%가 0 lux(낮은 밝기를 못 잼), 대로변 vs 주택가 구분 확률이 0.58로 위성(0.72)보다 낮다. 센서 바로 옆 가로등 유무에 따라 값이 크게 달라져 '동네 밝기'의 정답으로 쓰기 어렵다.

**결론:** 동네·거리 단위의 **상대 비교(상/중/하)로는 쓸 만하고**, 특정 창문의 **절대 조도(lux)로는 쓰면 안 된다.** 화면에는 "위성·상가 기반 추정"으로 표시하고 등급(3~5단계) 위주로 보여준다.

### 소음
| 검증 (Leave-one-out, 심야) | 값 |
|---|---|
| 상가 소음원 ↔ 실측 순위 상관 | 0.07 |
| 주변 센서 IDW ↔ 실측 | 0.14 |
| 거리 가중 혼합 ↔ 실측 | 0.17 |
| 오차(MAE) 혼합 / 평균값만 찍었을 때 | 6.4 dB / 6.5 dB |

- S-DoT 소음은 **센서 바로 옆 도로 여부**가 지배한다 (대로변 센서 61.5 dB vs 주택가 44 dB). 상가만으로는 설명력이 약하다.
- **도로 데이터(OSM)가 이 격자에는 빠져 있다.** 이 작업 환경에서 OSM 서버에 접근할 수 없었다. 기획서의 런타임 소음 엔진(Overpass 도로·철도·공항)과 함께 써야 한다.
- 센서에서 멀수록 신뢰도를 낮췄다(`noise_conf` 0.35~0.85). 가까운 센서 실측값과 거리를 함께 보여줄 것.

### 혼잡도
- 공식 통계(통신 기반 생활인구)라 신뢰도가 가장 높다. 다만 **동 단위**라 골목 차이는 없다.
- 확인: 서교동(홍대) 심야 100점, 역삼1동 83점, 안암동 26점, 주택가(보문동·종암동·상계1동) 0점.

## 4. 기획서·연동 가이드와 다르게 처리한 부분

| 항목 | 기획서/가이드 | 실제 처리 | 이유 |
|---|---|---|---|
| 시간대 | 기획서: 낮07–19/저녁19–23/심야23–07 | 가이드 4구간(day/evening/night/dawn) | API 계약이 우선. sensors.json에 24시간 값이 있어 기획서 구간도 계산 가능 |
| NASA 해상도 | 750m | 약 460m (15 arc-second) | VNP46 제품 사양 |
| 가로등 | 서울시 가로등 위치 정보(OA-22205) 사용 | **미포함** | 파일 미확보. 공간조명이 민원 원인 45%라 **추가 1순위** |
| 심야 실측 조도 | 1 lux→0, 30 lux→1 | 0 lux 측정값은 보정에 안 씀 | 0은 '어둡다'가 아니라 '측정 하한 아래' |
| 심야 1000 lux 초과 | — | 오작동으로 제거 (140건) | 밤에 불가능한 값 |
| 혼잡도 | 생활인구 그대로 | 새벽 3~5시 대비 늘어난 활동 인구 밀도 | 원값은 자는 주민까지 세서 주택가가 '밤에 붐빈다'로 나옴. 면적 미보정 시 큰 동이 무조건 높게 나옴 |
| 펜션·고시원 | — | 소음·빛 원인에서 제외 | 서울 펜션 8,117곳은 공유주택 등으로 추정 |
| 소음 도로·철도 | 포함 | 격자에는 미포함 | OSM 접근 불가. 런타임 엔진에서 처리 |

## 5. 신뢰도를 더 올리려면 (우선순위)
1. 서울시 가로등 위치 CSV 추가 → 빛 환경 지수에 공간조명 항 추가
2. OSM 도로·철도를 격자에 미리 반영 (팀원 PC에서 Overpass 호출 가능)
3. 데모 지역 3곳에서 휴대폰 조도·소음 앱으로 직접 측정해 추정값과 비교 → 발표 검증 자료
4. S-DoT 기간을 4~8주로 늘려 시간대 중앙값 안정화
